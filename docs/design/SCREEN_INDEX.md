## Quy ước lưu ảnh khi nhận được file gốc

- Đã xác nhận ảnh 01, 12, 24 hiện tồn tại trong repo; 21 ảnh còn lại cần kiểm kê riêng.
- Đặt file `docs/design/concepts/screen-01.png` đến `screen-24.png` (hoặc WebP nếu file nguồn là WebP; **không đổi phần mở rộng giả**).
- Lưu file gốc không chỉnh sửa; không dùng ảnh có UI làm background game.
- Sau khi upload, thay trạng thái cột “File ảnh” bằng link Markdown tương đối `[Xem ảnh](concepts/screen-XX.png)` **chỉ khi file tồn tại thật**.
- Xác minh ảnh 01–18 rồi cập nhật mã GDD, trạng thái trùng/thiếu và mô tả.
- Giữ các ảnh không khớp số GDD để tham khảo, không xóa chỉ vì khác thứ tự.
- Các concept này chỉ để tham khảo mỹ thuật và layout, **không phải** spritesheet, object hoặc animation production.
